
# Advanced ESP32 IoT Weather Station

An advanced IoT weather monitoring system built using ESP32 and a DHT sensor.

## Features
- Modular source structure
- REST API endpoint
- Web dashboard
- JSON formatted sensor data

## API
GET /api/weather

Example Response
{
  "temperature": 26.5,
  "humidity": 60
}

## Hardware
ESP32
DHT11 or DHT22
